# QR照合チェッカー

仕様書と型紙のQRコードを続けて読み取り、**同じ仕様書番号なら「ピンポン♪」、違えば「ブー」**と鳴らすツールです。

## Chrome拡張ではなくWebアプリにした理由

Chrome拡張機能は**スマホのChrome（Android / iOS）では動作しません**。スマホのカメラで読み取る用途では、ブラウザで開くWebアプリが唯一の方法です。
インストール不要で、iPhone・Androidどちらでも動きます（ホーム画面に追加すればアプリのように使えます）。

## 使いかた

1. Finderで **`スマホで開く.command`** をダブルクリック（Terminalが開きます）
2. 表示されたURL（例 `https://192.168.x.x:8443/`）をスマホのブラウザで開く
   - Macとスマホは同じWi-Fiに接続しておいてください
   - 「接続はプライベートではありません」と出たら **詳細 → このサイトにアクセスする** で進みます
     （自己署名証明書を使っているためです。通信自体は暗号化されています）
3. 「読み取り開始」を押してカメラを許可
4. **① 仕様書のQR** をかざす → 「ピッ」と鳴り、番号が表示される
5. いったんカメラから外し、**② 型紙のQR** をかざす
   - 一致 → **ピンポン♪** ＋ 画面が緑
   - 不一致 → **ブー** ＋ 画面が赤

終了するときはTerminalで `Control + C`。

> カメラは `https://` でしか使えないため、`index.html` をFinderからダブルクリックして開いてもカメラは動きません。必ず上記の手順で開いてください。

## 機能

| 機能 | 説明 |
|---|---|
| 仕様書を固定 | 1枚の仕様書に対して、複数の型紙を次々に照合するモード。①を読み直さずに②だけを連続で読み取れます |
| 数字だけで比較 | 記号や英字を無視して数字部分だけを比べます（片方だけに接頭辞が付いている場合など） |
| 音 / バイブ | それぞれ個別にオン・オフできます。テストボタンで確認できます（バイブはiPhoneでは使えません） |
| 画面の色 | 一致で緑、不一致で赤に画面全体が変わります。音が出せない場所やiPhoneでも判別できます |
| 履歴・CSV保存 | 判定結果を日時つきで記録します。「CSV保存」で検査記録として書き出せます |
| ライト / カメラ切替 | 暗い場所や、接写が苦手な広角カメラを積んだ端末向け |

番号の比較では、**全角・半角、空白、ハイフン、アンダーバー、英字の大小**の違いは同じものとして扱います。

## 音・バイブが鳴らないとき

画面下の **「🔊 音とバイブをテスト」** を押してください。ピッ → ピンポン♪ → ブー の順に鳴ります。ここで鳴らない場合は、原因は以下のどれかです。

### iPhone・iPad

- **バイブは使えません。** iOSのブラウザにはバイブ機能そのものがなく（Safari・Chrome・その他すべて）、Webページから振動させる方法はありません。代わりに、判定時に画面全体が緑／赤に光るようにしてあります。チェックボックスも自動で無効表示になります。
- **音はマナーモードで消えます。** 本体側面のスイッチがオレンジ（マナーモードオン）だと、Webページの音は鳴りません。スイッチをオフにして、音量を上げてください。
  iOS 16.4以降ではマナーモードを無視して鳴らす指定（`audioSession`）も入れていますが、効かない端末ではスイッチ操作が必要です。
- 画面を一度もタップしていないと音が有効になりません。「音がまだ有効になっていません」と表示されたら、画面をどこかタップしてください。

### Android

- バイブ・音とも動作します。鳴らない場合は、端末の**サイレントモード**や**メディア音量**を確認してください（着信音量ではなくメディア音量です）。
- 一部の機種では、省電力モード中にバイブが抑制されます。

### 共通

- 「音」「バイブ」のチェックが外れていないか確認してください。設定は端末に保存されるため、一度外すと次回も外れたままです。

## 動作確認

実物の仕様書・型紙がなくても試せます。Macで `test-qr.html` を開き（ダブルクリックでOK）、その画面をスマホで読み取ってください。同じ番号のQRと、わざと1桁だけ違うQRが並びます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `jsQR.min.js` | QR読み取りライブラリ（iPhone用。AndroidのChromeでは端末内蔵の高速な読み取り機能を使います） |
| `スマホで開く.command` | HTTPSサーバーの起動用 |
| `serve.py` | 同上（中身） |
| `test-qr.html` | 動作確認用のQRコード生成 |
| `qrcode.min.js` | QR生成ライブラリ（`test-qr.html` 専用。アプリ本体では使いません） |
| `.cert/` | 自動生成された証明書。消しても次回起動時に作り直されます |

すべてオフラインで動作します（インターネット接続・外部サービスへの送信は一切ありません）。

## 会社で複数人に配る場合

このアプリはオフライン対応（PWA）にしてあります。**正規のHTTPSで一度配信すれば、各自がホーム画面に追加するだけで、以降はサーバーを止めても圏外でも動きます。**

### 方法A：GitHub Pages に置く（おすすめ）

無料・恒久URL・正規の証明書つきで、証明書の警告が出ません。

**手順**

1. **`GitHub公開用フォルダを作る.command`** をダブルクリック
   → アップロードすべきファイルだけが入った「GitHub公開用」フォルダが開きます
   （サーバー用の秘密鍵など、公開してはいけないファイルは入りません）
2. [github.com](https://github.com) でアカウントを作り、**New repository** で新しいリポジトリを作る
   - 名前は `qr-check` など。**Public** を選択（無料プランでPagesを使う場合）
3. リポジトリの画面で **Add file → Upload files** を開き、
   「GitHub公開用」フォルダの中身を**すべて**ドラッグして **Commit changes**
4. **Settings → Pages** を開き、Source を `Deploy from a branch`、Branch を `main` / `/(root)` にして **Save**
5. 1〜2分待つと、同じ画面に公開URLが出ます
   → `https://ユーザー名.github.io/qr-check/`
6. このURLを全員に配る（QRコードにして貼っておくと楽です）

**注意点**

- 無料プランでは公開リポジトリになります。アプリ自体に会社の情報は一切含まれませんが（読み取った番号は各端末の中だけに保存され、外部に送信されません）、社内規定の確認はしてください。非公開にしたい場合は GitHub Team 以上の契約が必要です。
- 初回だけインターネット接続が必要です。以降はオフラインで動きます。

**アプリを更新するとき**

1. `sw.js` の `const VERSION = 'qrcheck-v1'` の数字を1つ増やす（`v2`, `v3`…）
2. `GitHub公開用フォルダを作る.command` をもう一度実行
3. GitHubで同じ手順でファイルを差し替える

各端末は次回起動時に新しい版を自動で取り込みます。番号を増やし忘れると古い版が残り続けるので注意してください。

### 方法B：社内Webサーバーに置く

正規の証明書があれば方法Aと同じように使えます。
自己署名証明書の場合は、**各端末で証明書の警告を承認する必要があり、かつオフライン対応（ホーム画面に追加して単独で動く機能）が使えません** — ブラウザが証明書エラーのあるサイトではオフライン機能を許可しないためです。

### 方法C：Macを立てたままにする

台数が少なく、全員が同じWi-Fiにいるなら現状のままでも使えます。ただしMacを起動し続ける必要があり、MacのIPアドレスが変わるとURLも変わります。オフライン対応も使えません。

### 各端末でやること

1. URLを開く → 「読み取り開始」でカメラを許可
2. **担当者名**を入力（CSVに記録され、誰の検査記録か分かるようになります）
3. ホーム画面に追加
   - iPhone：共有ボタン → 「ホーム画面に追加」
   - Android：メニュー → 「アプリをインストール」／「ホーム画面に追加」

### 記録の集めかた

履歴は**端末ごとに保存**されます（サーバーには送られません）。全員分をまとめたい場合は、各端末で「CSV保存」したファイルを集めてください。ファイル名に担当者名が入ります。
全員分を自動で1か所に集めたい場合は別途しくみが必要になるので、必要であればご相談ください。
